# yanyin.crm

A gamified SaaS platform for HoReCa: digital menu, ordering, kitchen display, stock, finance, staff quests, guest loyalty and the AI assistant Yan.

*The restaurant operating system your staff actually want to open.*

Status: **Phase 0, discovery and foundation.** No application code yet.
