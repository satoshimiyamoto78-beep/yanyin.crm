# Дорожная карта yanyin.crm

Принцип: **сначала показать «фан» и заработать доверие кухни, потом углубляться в операционку.** Игры и квесты входят в MVP с первого дня, потому что это наше отличие, а не бонус.

## Фаза 0. Фундамент (2–3 недели)

- [ ] Монорепо: Next.js, Supabase, Tailwind, shadcn/ui, линтеры, тесты, CI
- [ ] Схема БД ядра: organizations, locations, memberships, roles, RLS и тесты изоляции тенантов
- [ ] Авторизация: телефон (OTP) и email; приглашения в команду
- [ ] Дизайн-система: токены, тёмная и светлая темы, базовые компоненты, i18n (ru, uz, tg, en)
- [ ] Каркас yanyin.core: список заведений, создание, вход в аккаунт клиента
- [ ] Журнал `domain_events` и audit_log

## Фаза 1. MVP: «гости заказывают, персонал играет» (~3 месяца)

**yanyin.menu (гость)**
- [ ] QR-меню: категории, фото, модификаторы, фильтры, аллергены, мультиязычность
- [ ] Заказ со стола в общий счёт стола; кнопки «Позвать официанта» и «Счёт»
- [ ] Food Roulette: бюджет + настроение → набор блюд
- [ ] Mystery Dish

**yanyin.hq (менеджер)**
- [ ] **AI-добавление блюда (ADR-007):** фото + заметка или голос → черновик карточки (описание, ингредиенты, аллергены, КБЖУ «примерно», переводы), улучшение фото, проверка и публикация
- [ ] AI-импорт всего меню по фото бумажного меню (онбординг)
- [ ] Редактор меню с drag-and-drop, стоп-лист, расписание меню
- [ ] Столы и залы, генерация QR-кодов (PDF для печати)
- [ ] Техкарты v1 и автосписание со склада при продаже
- [ ] Дашборд: выручка, топ блюд, средний чек, живые столы
- [ ] Конструктор квестов v1: метрика, цель, срок, награда

**yanyin.crew (персонал)**
- [ ] Заказ официантом с телефона, мои столы, уведомления
- [ ] Квест-доска, прогресс, XP, уровни
- [ ] Личная страница: мои продажи, чаевые, цели

**yanyin.kitchen**
- [ ] KDS: очередь в реальном времени, статусы, таймеры, стоп-лист

**Платежи и фискализация (по выбранному первому рынку)**
- [ ] 1–2 платёжных провайдера + наличные/карта у официанта
- [ ] Интеграция с одним провайдером виртуальной кассы / ОФД

**Критерий готовности MVP:** одно реальное заведение-пилот работает на системе целую смену без бумажных заказов, а чеки проходят фискализацию.

## Фаза 2. Операционка (месяцы 4–6)

- [ ] Инвентаризация с телефона, ожидаемое против фактического, отклонения
- [ ] Поставщики, заявки, автозаказ по минимальному остатку, FIFO и сроки годности
- [ ] Food cost по блюду в реальном времени, P&L, prime cost, экспорт бухгалтеру
- [ ] Смены, учёт времени по QR, расчёт бонусов и зарплаты
- [ ] Бейджи, командные квесты, «босс недели», kudos, отключаемые лидерборды
- [ ] yanyin.club v1: баллы, уровни, профиль гостя, день рождения, карты в Wallet
- [ ] Сплит-счёт, чаевые онлайн, оплата со стола через QR
- [ ] Биллинг подписок в yanyin.core: тарифы, пробный период, счета, MRR

## Фаза 3. Интеллект (месяцы 7–9)

- [ ] AI Yan для гостя: чат-официант, подбор, безопасность при аллергии
- [ ] AI Yan для менеджера: вопросы к данным обычным языком, утренний отчёт
- [ ] AI Yan для персонала: техкарты голосом, подсказки апсейла
- [ ] Рекомендательный движок: контекст, маржа, остатки
- [ ] Menu engineering (Stars / Plowhorses / Puzzles / Dogs) с советами
- [ ] Прогноз спроса и закупок
- [ ] Контроль расхода AI в yanyin.core
- [ ] Аналитика эффекта квестов: апсейл, текучка, средний чек до и после

## Фаза 4. Масштаб

- [ ] Сети и франшизы, центральная кухня, перемещения
- [ ] Агрегаторы доставки (через Delever и напрямую)
- [ ] Открытый API и маркетплейс интеграций
- [ ] White-label гостевого приложения
- [ ] Мобильные приложения (Expo), офлайн-режим с синхронизацией
- [ ] Второй рынок (UZ ↔ TJ), затем Казахстан и Кыргызстан

## Тарифы (черновик)

| Тариф | Что входит | Цель |
|---|---|---|
| **Free** | QR-меню, редактор меню | Вход в воронку |
| **Starter** | + заказы, KDS, базовый дашборд, Food Roulette | Малые кафе |
| **Pro** | + склад, техкарты, финансы, персонал, квесты, лояльность | Основной тариф |
| **Ultimate** | + AI Yan, мультилокации, прогнозы, API | Сети |
| Доп. доход | Комиссия с онлайн-платежей, AI-кредиты, филиалы, white-label | Расширение |

Цены в местной валюте определим после интервью с клиентами (см. `04-decisions.md`).
